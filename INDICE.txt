COMO USAR CADA FERRAMENTA:
════════════════════════════════════════════════════════════════

TESTAR NO NAVEGADOR:
  F12 → Ctrl+Shift+M → Escolher dispositivo

TESTAR VIA CONSOLE:
  ResponsiveTestHelper.testDevice('iPhone 14 Pro')

APLICAR CLASSE NO CSS:
  @media (min-width: 768px) {
    /* Seu CSS aqui */
  }

USAR CLASSE UTILITÁRIA:
  <div class="mobile-only">Só em celular</div>

VERIFICAR NO JAVASCRIPT:
  if (ResponsiveHelper.getCurrentSize() === 'md') {
    // Faz algo no tamanho md
  }

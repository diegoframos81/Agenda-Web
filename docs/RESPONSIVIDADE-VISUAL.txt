  │  <─────────>   │  Largura > Altura

CLASSES DINÂMICAS APLICADAS
===========================

Ao carregar a página, <html> recebe:

size-xs              ← Tamanho detectado
device-phone         ← Tipo de device
portrait             ← Orientação
os-ios               ← Sistema operacional

Exemplo resultado:
<html class="size-md device-phone portrait os-android">


USO EM CSS
==========

html.size-md .card {
  max-width: 300px;  /* Aplicado em tamanho md */
}

html.device-phone button {
  min-height: 44px;  /* Botões maiores em celular */
}

html.landscape .topbar {
  flex-direction: row;  /* Em landscape, linha */
}
